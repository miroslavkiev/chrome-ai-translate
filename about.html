About AI Translator

Super easy translation: select text and press Control.

Made for people

I created AI Translator to help people read, learn, and connect across languages. I hope it is useful to people around the world.

The extension translates the text you select using your own Google Gemini API key. You choose what to send and which language to read.

Tap and release Control to translate your selection. Control is the default key and can be changed in Settings. You can also use the page's right-click menu.

Manually tested on Mac only. Windows and Linux have not been manually tested.

Privacy and costs

Your API key stays in local extension storage and is not synced. Selected text is sent directly to Google only when you ask for a translation. The extension has no analytics, advertising, or translation history.

Google API use can have costs and is covered by Google's pricing and data-use notes and Gemini API terms. AI Translator is an independent project.
