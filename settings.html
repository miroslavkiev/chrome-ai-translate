Set up AI Translator

Follow these steps here in Settings. You need your own Google API key to translate.

  1. Get your own API key. Open Google AI Studio, sign in, and create a key. Paste it in the API key field below. Read the step-by-step guide for help.
  2. Choose your target language and model. Pick the language you want translations in. We recommend Gemini Flash-Lite when it is available in your model list.
  3. Save and start translating. Use Finish setup at the bottom of this page. Then select text on a web page and choose Translate Selected Text from the right-click menu.

Gemini

Connect your own Gemini API key and choose a compatible model.

Selected text and your target language go directly to Google when you ask for a translation. Your key is sent to Google to load models and translate. It is currently saved without encryption in this browser profile. Read the privacy details before adding a key.

Google's current API terms require adult professional or business use. Apps offered in the European Economic Area, UK, or Switzerland must use a project with active billing. Read the requirements and key guide.

Help and recovery

If a model is unavailable, refresh models, choose one from the list, and save preferences. If the list cannot load, check your key and connection, then try Refresh models.

Chrome settings pages and the Chrome Web Store do not allow translation. For local files, enable Allow access to file URLs in Manage Extension. After an extension update or reload, refresh open web pages. Reloading can interrupt a translation.

Privacy

This extension runs locally, but translation is not offline: selected text, including text from local files, is sent directly to Google. Your API key stays in local extension storage. Your language, model, and trigger preference can sync through Chrome. Selected text is sent to Gemini only when you request a translation. The extension keeps only the latest result for this browser session and does not keep translation history.
